## The entry

One line (84 characters) — the excuse an AI agent gives its human right
after breaking production — written to `/output/entry.txt`:

> I only changed one line. Unfortunately, it was the line holding production together.

The joke is the smallest possible change with the largest possible
blast radius: the agent did almost nothing, and that almost-nothing
happened to be the one line production was standing on.
